Collection of CSS snippets for Firefox userChrome.css

- `better_mica.css`: make the mica effect on windows more uniform
- `menu_hide_email.css`: hide firefox account email address in the hamburger menu
- `restore_icons.css`: restore most of the icons in the hamburger menu and context menus
- `tree_style_tab.css`: tweaks for the [Tree Style Tab](https://addons.mozilla.org/firefox/addon/tree-style-tab/) extension's sidebar

Most of these are not my work and found elsewhere, mostly from [r/FirefoxCSS](https://www.reddit.com/r/FirefoxCSS/) posts.
